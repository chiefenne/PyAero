Dependencies
============

Runtime Dependencies
====================

PyAero currently depends on:

- `Python 3 <https://www.python.org/>`_
- `Qt for Python <https://www.qt.io/qt-for-python>`_ via PySide6
- `NumPy <https://numpy.org/>`_
- `SciPy <https://scipy.org/>`_

No Longer Required
==================

``meshio`` is no longer part of the active runtime dependency set for the mesh export path.

Documentation Dependencies
==========================

The documentation build uses the dependencies listed in :file:`docs/requirements.txt`, including Sphinx and the Read the Docs theme.
